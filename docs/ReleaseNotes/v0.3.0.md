# SubRadar iOS v0.3.0

Первый релиз в новом самостоятельном репозитории — код перенесён из
`OctopyApps/SubRadar` (директория `ios/`) с сохранением истории коммитов.

## Что нового с v0.1.2

### Синхронизация с бэкендом

Модели (`Subscription`, `AppCategory`, `AppCurrency`) и слой хранения
(`StorageService`, `RemoteStorageService`, `APIClient`) доработаны под
актуальный контракт бэкенда — устранены расхождения в сериализации,
улучшена обработка ошибок сервера.

### Надёжность переключения режима хранения

`ServerSetupView`/`ServerSetupViewModel` и `StorageModeSettingsView`
доработаны — переключение между локальным, self-hosted и централизованным
режимом хранения стало надёжнее, добавлена более явная обратная связь при
ошибках подключения.

## Требования

- iOS 17+
- Для режима синхронизации: [SubRadar Backend](https://github.com/OctopyApps/SubRadar-BackEnd) v0.3.0+
