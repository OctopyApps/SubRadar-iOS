# SubRadar iOS

SubRadar iOS-клиент. Swift + SwiftUI, минимальная версия iOS 17,
локальное хранилище — SwiftData, архитектура — MVVM.

## Разработка

```bash
git clone https://github.com/OctopyApps/SubRadar-iOS.git
cd SubRadar-iOS
open SubRadar/SubRadar.xcodeproj
```

Три режима хранения данных — локально на устройстве, self-hosted сервер
(см. [SubRadar-BackEnd](https://github.com/OctopyApps/SubRadar-BackEnd)),
или централизованный сервер.
